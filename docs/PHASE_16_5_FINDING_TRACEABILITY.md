## 3. Newly Discovered Phase 16.5 Findings

| Finding ID | Severity | Applicable Scope | Root Cause | Description | Impact |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **FINDING-16.5-01** | **CRITICAL** | Scope C & D (Multi-Worker / Multi-Tenant) | In-Memory Caching Divergence (`approvals.py:221`) | `HumanApprovalEngine.get_approval()` returns cached in-memory instance without querying DB. In a multi-worker cluster, nodes cast votes against stale local snapshots. | Approval requests with quorum approvals become permanently stuck in `PENDING` status. |
| **FINDING-16.5-02** | **HIGH** | Scope E (Financial / Irreversible) | In-Memory Idempotency & Blind Restart (`engine.py:446`) | `recover_after_restart()` resets `RUNNING` tasks with expired leases to `READY`. `_task_idempotency_cache` is held in RAM only and lost on crash. | Non-idempotent automated tasks (e.g. wire transfer, API charge) interrupted by host crash are re-executed upon restart. |
| **FINDING-16.5-03** | **MEDIUM** | Scope C (Multi-Worker PostgreSQL) | Initial Lease Unlocked Select (`storage.py:1550`) | On newly instantiated tasks where no lease row exists, `SELECT ... FOR UPDATE` locks 0 rows. Multiple competing workers can both receive `fencing_token = 1`. | Fenced worker runs until completion before failing at verification; inefficient duplicate work. |
| **FINDING-16.5-04** | **MEDIUM** | Scope C, D, E (Network Perimeter) | DNS Rebinding TOCTOU (`connectors.py:771`) | DNS resolution occurs during validation; `httpx` issues a second DNS query during TCP connection. Dynamic TTL=0 domains can rebind to private IPs. | Requires network-level egress enforcement (NetworkPolicy / Proxy) in enterprise environments. |
